# Wine Recommendation System

A content-based recommender that suggests similar wines using TF-IDF
and cosine similarity on the Kaggle Wine Reviews dataset.

## Dataset
Wine Reviews (Kaggle): https://www.kaggle.com/datasets/zynicide/wine-reviews
Download the CSV and place it in the project folder.

## Approach
1. Cleaned the data (duplicates, missing values)
2. Explored ratings, prices, countries and varieties
3. Combined variety, origin, winery and description into one text field
4. TF-IDF vectors + cosine similarity
5. recommend() function with an optional price filter
